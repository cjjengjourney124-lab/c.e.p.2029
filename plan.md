Here is your complete, browser-based Portfolio Development Plan. This roadmap connects your coding (Replit/Khan Academy), 3D modeling (Onshape), and PLTW engineering classes into a professional showcase for Reach and Target colleges—all without installing a single piece of software.

Phase 1: Set Up Your Launchpad (GitHub)

Estimated Time: 1–2 hours
Before building new things, set up your storage center. GitHub is your digital filing cabinet.
• Create Your Profile: Go to GitHub.com and register a professional username (e.g., FirstnameLastname-Eng).
• Create a "Small-Projects" Repository:
	• Click New Repository, name it portfolio-snippets, and check the box to add a README.md file.
	• Open your old projects on Replit or Khan Academy. Copy the code files, and upload them directly into this repository using the "Upload files" button in your browser.
• Write the Descriptions: Click the pencil icon to edit your README.md file. Write a short paragraph explaining what each snippet does (e.g., "A Python physics calculator built on Replit to solve acceleration equations").

Phase 2: The Core Project Build (Onshape + Replit)

Estimated Time: 4–6 weeks (working 2 hours a week during Next Semester)
This is the "Bigger Project" that will anchor your portfolio: the Multi-Part Virtual Robotic Arm.
• Weeks 1–2: Onshape Training & Part Design
	• Complete the "Introduction to Assembly Design" video path on the Onshape Learning Center.
	• Design your 4 core parts (Base, Lower Arm, Upper Arm, Claw) in a single Onshape Part Studio.
• Weeks 3–4: The Assembly
	• Open the Assembly tab in Onshape.
	• Apply Revolute Mates to connect the arm segments so they rotate cleanly.
	• Portfolio Action: Use your computer’s built-in screen recorder to capture a 10-second video of you clicking and dragging the arm to show its full range of motion.
• Weeks 5–6: The Replit Simulation Code
	• Go to Replit and create a new Python project named robotic-arm-simulator.
	• Write a text-based console program where a user types commands (like EXTEND, RETRACT, OPEN CLAW) and the screen prints out the robot's simulated joint angles or coordinates.
	• Portfolio Action: Push this code directly from Replit to a new, dedicated repository on your GitHub account.

Phase 3: Build the Public Portfolio Website (GitHub Pages)

Estimated Time: 3–5 hours
Now, use your Khan Academy HTML/CSS skills to build a gorgeous portfolio site hosted completely free by GitHub.
• Create the Host Repository: Create a brand new repository on GitHub named exactly username.github.io (replace username with your actual GitHub username). This tells GitHub to turn this folder into a live website.
• Draft the Code (index.html): Create a file named index.html inside that repository. Use a clean, simple layout with these sections:
	• About Me: "Sophomore at Captain Shreve High School | Aspiring Engineering Student | PLTW POE."
	• 3D Modeling Showcase: Insert the screenshots of your Onshape robotic arm assembly. Provide a hyperlink to your public Onshape document.
	• Coding Showcase: Embed links to your Replit projects and display a button linking to your GitHub profile.
	• PLTW Engineering Log: Write a few bullet points about your favorite lab builds or testing procedures from your Principles of Engineering class.

📅 Your Weekly Routine Next Semester

To balance this with Geometry and your other classes, do not try to do this all at once. Treat it like a low-stress hobby:
• Monday–Thursday: Focus 100% on keeping an "A" in Geometry and crushing your PLTW assignments.
• Friday Afternoon or Saturday Morning: Dedicate just 1 to 2 hours to your portfolio work. Work through one Onshape video tutorial, upload one old coding script to GitHub, or add a sentence to your portfolio website.
By the time you start your junior year, you will have a live portfolio link that you can show to teachers for letters of recommendation and eventually hand straight to admissions officers at MIT, Georgia Tech, or Michigan.
